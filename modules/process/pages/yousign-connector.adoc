== Overview

The Yousign connector provides eight operations to manage electronic signature workflows:

* **Create From Template** -- create a signature request from a Yousign template
* **Activate** -- activate a signature request (sends invitations to signers)
* **Get Status** -- retrieve the current status of a signature request
* **Cancel** -- cancel an active signature request
* **Download Document** -- download signed documents (single or ZIP)
* **Download Audit Trail** -- download the audit trail PDF
* **List** -- list signature requests with filters and pagination
* **Register Webhook** -- register a webhook for signature events

=== Signature request lifecycle

A signature request follows this lifecycle:

----
draft --> approval --> ongoing --> done
                         |
                         +--> declined
                         +--> canceled
                         +--> expired
----

* **draft** -- The request has been created but not yet activated
* **approval** -- The request is pending internal approval (if configured)
* **ongoing** -- Signers have been invited and the request is awaiting signatures
* **done** -- All signers have signed; documents are available for download
* **declined** -- A signer has declined to sign
* **canceled** -- The request was canceled by the initiator
* **expired** -- The request passed its expiration date without completion

== Prerequisites

Before using the Yousign connector, ensure the following:

* A https://yousign.com/[Yousign] account with API access
* A **Yousign API key** obtained from your Yousign account settings
* At least one **signature template** configured in Yousign (for the Create From Template operation)
* The connector extension imported into your Bonita project (see <<import-connector>>)

TIP: Yousign provides a **sandbox environment** for testing. Use the sandbox API key and base URL (`\https://api-sandbox.yousign.app/v3`) during development to avoid triggering real signature workflows.

|===
|Output name |Type |Description

|*success*
|Boolean
|`true` if the operation completed successfully, `false` otherwise.

|String

|===

== Error handling

The connector handles HTTP errors as follows:

|===
|HTTP code |Behavior

|400
|Fail immediately (validation error)

|401
|Fail immediately (authentication error)

|403
|Fail immediately (access denied)

|404
|Fail immediately (resource not found)

|429, 5xx
|Retry up to 3 times with exponential backoff (1s, 2s, 4s)
|===

Creates a signature request from a pre-configured Yousign template.

|===

|*templateId*
|String
|Yes
|The UUID of the Yousign template to use.
|

|*requestName*
|String
|Yes

|String
|Yes

[#import-connector]
== Importing the connector into Bonita Studio

To use the Yousign connector in your Bonita project:

. Download the connector `.zip` extension from the https://marketplace.bonitasoft.com/[Bonita Marketplace].
. In Bonita Studio, go to the *Project* menu and select *Extensions*.
. Click *Import extension* and select the downloaded `.zip` file.
. The Yousign connector operations will appear in the connector palette when configuring a task or a process.

For more details on managing extensions, see xref:bonita-overview:managing-extension-studio.adoc[Managing extensions in Bonita Studio].

== Troubleshooting

=== Common errors

[cols="1,2,2"]
|===
|Error |Cause |Solution

|`Authentication error: invalid API key`
|The API key is invalid, expired, or for the wrong environment.
|Verify the key in the Yousign dashboard. Ensure sandbox keys are used with the sandbox URL and production keys with the production URL.

|`Resource not found`
|The signatureRequestId or documentId UUID does not exist.
|Verify the UUID is correct. Check that the resource has not been deleted.

|`Bad request: invalid template`
|The template ID is invalid or the signer label does not match any role in the template.
|Verify the template exists in your Yousign account. Check that the `signerLabel` exactly matches a role defined in the template.

|`Rate limit exceeded`
|Too many API calls in a short period.
|The connector automatically retries 3 times with exponential backoff. If the error persists, reduce polling frequency.

|`Access denied`
|The API key does not have sufficient permissions.
|Check the API key permissions in the Yousign dashboard.
|===

=== Status transition errors

[cols="1,2"]
|===
|Scenario |Explanation

|Cannot activate a request
|The request must be in `draft` or `approval` status. It may have already been activated, canceled, or expired.

|Cannot cancel a request
|The request must be in `draft`, `approval`, or `ongoing` status. Terminal states (`done`, `declined`, `expired`) cannot be canceled.

|Cannot download documents
|Documents are only available when the request is in `done` status. Check the status before attempting to download.

|Webhook not receiving events
|Verify the endpoint URL is publicly accessible over HTTPS. Check the webhook status in the Yousign dashboard.
|===
