== New available values

=== Task Delegation

[NOTE]
====
For Teamwork, Efficiency, Performance, Enterprise and Scale editions only. +
====

When a user is away, their pending tasks normally stay invisible to everyone else. Task Delegation lets a designated delegate see and perform those tasks on behalf of the absent user, without reassigning them, and keeps full traceability of who acted.

This feature is delivered through a new Subscription living application, *Bonita User Application Enterprise*, which replaces the community *Bonita User Application* and adds the delegation pages.

*On a fresh installation*, the *Bonita User Application Enterprise* is installed automatically. Nothing else to do.

*When updating from a previous Bonita version*, your existing *Bonita User Application* is kept and the new *Bonita User Application Enterprise* is added alongside it, so the two applications coexist. A manual step is required to finish the setup, depending on your situation:

. *You did not customize the Bonita User Application* — open Bonita Studio, open *Extensions* from the *Overview*, safely remove the *Bonita User Application*, then import the *Bonita User Application Enterprise* from the Marketplace.
. *You customized the Bonita User Application and want to keep it as is* — import the two new pages `page-admin-delegation` and `page-user-delegation`, and add them to your application's menu entries. The two pages are available inside the *Bonita User Application Enterprise* archive, which you can download from the xref:software-extensibility:bonita-repository-access.adoc[Bonita Artifact Repository] with:
+
[source, bash, subs="+macros"]
----
mvn dependency:copy -Dartifact=com.bonitasoft.web.application:bonita-user-application-sp:pass:a[{bonitaTechnicalVersion}]:zip:application -DoutputDirectory=./outputDir
----
. *You customized the Bonita User Application and want to move to the new one* — backport your customizations into the *Bonita User Application Enterprise*.

== Notable changes

=== User Application process list migrated to Svelte

The provided process list page of the xref:runtime:user-process-list.adoc[Bonita User Application] has been re-implemented with the Svelte framework, replacing the previous React implementation. Existing customizations that target the page through application descriptors continue to work; teams that have forked the page source should port their changes to the new Svelte codebase.

The full dependency list for Svelte-based provided pages is available at xref:dependencies:svelte-page-dependencies.adoc[List of Svelte pages dependencies].
